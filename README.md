# GRPC Microservices

## Prerequisites

* **Go** `1.22` or higher

## Getting Started

1. Clone the repository:
   ```bash
   git clone [https://github.com/zannunakiz/GRPC-Micro-GO.git](https://github.com/zannunakiz/GRPC-Micro-GO.git)
   cd GRPC-Micro-GO

```

2. Download dependencies:
```bash
go mod download

```


3. Run the application:
```bash
go run .

```
